**Realtime голосовой агент — 3 итерации** (личный R&D, _апр 2026 — н.в._) · [v1](https://github.com/prineycom/voice-agent) · [v2](https://github.com/prineycom/voice-agent-v2) · [v3](https://github.com/yokeloop/voca)

- Собрал speech-to-speech агента реального времени целиком — транспорт WebRTC, потоковый STT → LLM → TTS с возможностью перебить агента и 3D-аватар, чьё лицо следует эмоции голоса, — и уместил весь стек на одну видеокарту 12 ГБ: снизил память NVIDIA Audio2Face-3D с 8,8 ГБ до ~0,4 ГБ, пересобрав его TensorRT-движок, и время анимации лица с ~3 с до 81 мс на фразу через постоянный C++-хелпер инференса.
- Дал ему руки: агент превращает речь в вызовы инструментов, проверенные по схеме, выполняет их в закрытой Docker-песочнице и отправляет результаты в Telegram; v3 расширяет это до делегирования задач coding-агентам. Каждый выбор модели — STT, LLM, TTS — проходил заданные мной пороги по задержке, real-time factor и VRAM и зафиксирован в 37 ADR; третью версию осознанно переписал, признав вторую переусложнённой.

**Local-first лаборатория агентов** (личный проект, _фев 2026 — н.в._)

- Веду Priney — своего постоянно работающего персонального ассистента на Hermes Agent, развёрнутого на Raspberry Pi 5: задачи, календарь, почта, финансы, здоровье, знания и путешествия. Спроектировал его Second Brain — Obsidian-хранилище из 226 заметок с правилами, где агенту читать и куда писать, синхронизация через CouchDB и git — с локальным RAG по нему (ONNX-эмбеддинги, векторы в SQLite, инкрементальная переиндексация); написал его MCP-интеграции и cron-автоматизации (монитор с приоритетами и тихими часами, сводки, бэкапы).
- Развернул Qwen3.6-35B-A3B основной моделью своих агентов на одной видеокарте 12 ГБ (выгрузка MoE-экспертов на CPU, квантованный KV-кэш, контекст 262K) и добился надёжной работы агента на ней: нашёл причину молчаливого отказа от вызова инструментов — сжатие контекста схлопывало пары tool_call / tool_result — и исправил её принудительным вызовом инструментов и сжатием, сохраняющим историю вызовов; нашёл баг в апстриме, из-за которого локальный прокси LiteLLM принимался за локальную модель и таймаут стрима растягивался до 30 минут; тестировал LFM, Gemma и Qwen на видеокарте и на Pi.
- Написал [sp-cli](https://github.com/prineycom/sp-cli) — open-source CLI на Python и MCP-сервер для приложения Super Productivity: 97 команд, MCP-инструменты генерируются из самого CLI, 919 тестов, CI на Python 3.11–3.13; собран за 2 дня автономной агентной сессией по workflow yoke.
